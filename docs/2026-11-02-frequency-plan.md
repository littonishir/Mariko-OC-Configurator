# 分档频率建议与实现计划

已授权范围：保留解锁建议打开、CPU UV 0/0 与 VMIN 620/750、GPU HiOPT 610、RAM1600/DVB0/默认时序；恢复有依据的差异化频率建议。用户进一步指定只提供“保守配置 / 进阶配置”，不附“待实机验证”标签，直接给合理配置。只改助手，不改整合包或主机。

## 规则

- 保守配置运行 RAM1600/CPU1020/GPU384或768；进阶配置直接展示所选频率。共用 KIP 参数不变，两套频率汇总同时显示，选定方案查看详细参数。
- CPU 使用 HOC2.6.0 的实际 TBREAK1683 CVB 表（pcv.hpp 会按 tableConf 选表），不是误用 HOS 默认表。UVHigh0 的频率表边界为1963.5 MHz，自动建议不超过此值。
- GPU 使用 HiOPT 表，结合 Speedo、温度范围和场景过滤。计算值是模型估算，不是测量值；不开额外偏移，不修改 VMIN。
- CPU/GPU 候选筛选使用本工具明确标注的电压预算；预算只是减少候选范围的产品策略，不声称是上游安全线。
- RAM 按 Hekate v6.5.4 可核对的规格：MGCJ/NME 为3733Mbps→1866MHz；WT:B/E/F、MGCL、NEE/X267 为4266Mbps→2133MHz。NEI/MGCR 未核实速度等级，保持1600。规格不当作稳定性结论。
- 按用户最新要求简化，不增加实测记录表单；仅保守和进阶两个方案。供电场景区分掌机/普通USB/官方充电器与底座。
- 来源、候选、路线、已验证值和回退提示在网页、文本、PNG中一致。
