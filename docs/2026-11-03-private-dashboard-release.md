# 私有参数后台发布记录

用户请求网页展示线上数据，选择“仅自己查看，需要登录保护”。实现 `/admin`，同一 Worker 服务，公开网站静态文件无改动。

- 后台：https://hoshino-hoc-device-samples.hoshino-hoc.workers.dev/admin
- Worker 部署 ID：`00c7ea6b11784eb892a368871f8f14eb`。
- 视图：参数组合数、接收次数、内存 ID 种类，机型/颗粒筛选，25条分页，中文标签、北京时间。
- 保护：随机高强度密码哈希作为 secret，随机 Cookie 会话仅存哈希，8小时有效，退出撤销；登录限流与只读API。
- 初始化密码只保存项目外权限600文件，不进入公开源码、HTML或本文档。

## 验证

- 全部48项测试通过，cf 生产构建与 dry-run 通过。
- 独立审查：无认证绕过或重要问题；修复筛选变更后的分页问题，并写明换密码需要撤销旧会话。
- 真实浏览器发现原生表单在 no-referrer 策略下 Origin 会被抑制；调整后台为 same-origin，并在真实浏览器复验登录、筛选、退出。公开采集 reporter 仍使用 no-referrer。
- 本地桌面和390px手机页面可用，未出现整页横向溢出；表格区域单独滚动。
- 正式环境同源浏览器流程：未登录 API401，密码登录后读API200，页面含数据表格，退出后API401；正式库当时空库。
- 正式 GitHub Pages 来源采集接口返回204，D1核对测试参数后只清理明确标记的合成样本；后台测试会话也已清理。
- `npm run db:list` 保留查询本地库行为，不会自动切换线上。

## 维护

读取 API 为 `/admin/api/samples`，受服务器会话保护、no-store，无跨域开放。密码重置与会话撤销操作见 `api/README.md`。
当前 workers.dev 在部分网络不可达，后台受同样影响；后续可绑定自有域名，未改变现有采集或网站域名。
