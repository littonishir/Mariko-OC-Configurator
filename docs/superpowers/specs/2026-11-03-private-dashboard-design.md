# 私有设备参数展示页

用户希望通过网页查看已采集的线上体质和内存 ID，选择“仅自己查看，需要登录保护”。沿用同一 Worker/D1，在 `/admin` 新增密码登录页和只读后台，不改变公开配置网页与参数接收行为。

第一版：显示参数组合数、接收次数、内存种类，按内存 ID/机型筛选；每页 25 条，最新提交优先；表格包含三种 Speedo、RAM ID、机型、场景、目标、次数和北京时间，提供刷新、翻页和退出。明确数据是填写样本，不是去重人数或稳定性结果。

实现者选择：服务器校验随机生成的高强度初始密码，其 SHA-256 作为 Worker secret `ADMIN_PASSWORD_HASH`；密码明文仅保存于项目外权限 600 的本地登录信息文件，不进 Git。无须开通 Cloudflare Access。

登录创建 32 字节随机会话令牌；数据库 `admin_sessions` 只存令牌哈希和 8 小时有效期。Cookie 为 `__Secure-hoc_admin`，Secure、HttpOnly、SameSite=Strict、Path=/admin。退出删除数据库会话并清理 Cookie；失效/篡改令牌不可读数据。缺失密码/DB/登录限流绑定时后台关闭，不影响采集。登录限流每来源 IP 5 次/分钟（平台近似限制，IP 只作瞬时限流键不入样本数据库）。

所有后台响应 no-store；管理 API 不允许跨域，登录与退出 POST 校验 Origin，登录体最多 512 字节。静态 HTML 不嵌入密码或样本，使用 nonce CSP 与 textContent 渲染返回值，禁止被嵌入 iframe。列表与统计仅在有效会话下参数化查询，不提供修改删除功能或任意 SQL。页码限制 0–10000，RAM 筛选最多 32 字符，固定大小 25。

本地用真实 Worker/D1 测试未登录拒绝、密码错误、登录限流、Cookie 属性、篡改/过期/退出失效、只读过滤分页、恶意 RAM 文本、不改变既有采集。检查后部署同一 Worker，在正式页面验证登录/列表/退出和未登录拒绝；不公开密码，不导入本地数据，不删用户样本。
