# 设备参数样本接口

## 目标与已确定的行为

用户希望获取配置助手使用者填写的体质与内存 ID。2026-11-03 明确要求：用户点击“生成配置”时上传，不弹窗或显示上传提示。

- 仅显式提交且本地校验成功后发送；首次打开、修改字段自动重算、填入示例、复制和保存图片均不触发上传。
- 生成与图片导出仍在本地完成。请求不阻塞配置生成；断网、超时、403/429/500 或接口未配置均静默跳过，不改变配置和按钮文案。
- 沿用现有布局和推荐算法；不触及 HoshinoAtmosphere。新功能先在本地验证，生产部署与网页发布仍需最终验收。

## 数据与解释

请求字段固定为 schemaVersion=1、appVersion、cpuSpeedo、gpuSpeedo、socSpeedo、ramId、model、mode、goal。
Speedo 必须为 1200–2000 整数，与现有表单一致；1300–1849 以外的合法输入仍是输入样本，不能因此宣称已覆盖推荐模型。
RAM ID 去首尾空白、转大写，1–32 字符；不要求一定属于已知颗粒。
不发送姓名、账号、主机序列号、密钥、截图、游戏信息、完整 URL 或浏览器指纹，不增加 Cookie 或持久访客标识。数据库不存 IP。

同一规范化 CPU/GPU/SoC/RAM/model 元组保存一行，记录首次/最近接收时间、接收次数和最近一次场景/目标/网页版本。
这是用户自行填写的参数库，不是可信硬件扫描，也不是去重设备数量或实机稳定性反馈；固定示例、误填、随机输入仍可能进入样本库。
客户端在当前页面对已经成功上传或上传中的同一完整提交内容去重；失败后可通过再次点击重试，不自动重试。

## 实现选择（实现者决定）

- 保留 GitHub Pages 前端，新增独立 Cloudflare Worker 与 D1，不迁移网站。
- 新接口 POST /api/device-samples，JSON 请求体上限 2048 字节（流式读取也限长）。服务端独立校验类型、范围、枚举和字段白名单，拒绝额外字段。
- RAM ID 允许 Unicode 文本但拒绝控制字符，避免因未知颗粒名称丢失样本；SQL 使用参数绑定。
- CORS 精确允许配置的 Origin；生产仅允许 https://littonishir.github.io，本地单独允许 http://127.0.0.1:18765 / http://localhost:18765。CORS 不能防止脚本伪造输入。
- 只提供写入及 /healthz，公开接口不提供数据读取。拥有 Cloudflare 账号权限的人可在 D1 后台查看和导出。
- 平台 rate-limit binding 对整个接收端点限速 120 次/分钟/Cloudflare 节点，近似而非全球硬限制；不以 IP 作为样本或访客标识。缺少数据库或限流绑定时拒绝写入。
- 使用 D1 唯一约束和 UPSERT 原子去重并累加，不靠先查后写；不使用 KV 或队列。
- 前端可配置 endpoint，生产默认留空以避免未经验收上线；本地端点通过本地配置启用。请求超时 3 秒，credentials=omit，无重试，不读取返回的样本数据。
- 新 Worker 使用 2026-11-03 compatibility date；cf CLI 管理配置，Miniflare 运行真实 Worker/D1 的本地测试。源码和参数可提交 Git，无凭据进入仓库。

## 验收

1. 既有 20 项推荐/导出控制器测试通过。
2. 浏览器点击一次有效生成，D1 出现对应参数；编辑字段只重算，不写入。
3. 相同硬件参数并发提交不出现重复行；接收次数为请求数，不解释为用户数。
4. 非法值、额外敏感字段、超长请求、错误 Origin/方法和限流不写入；GET 不返回样本。
5. 网络失败/超时下仍能生成、复制；上传无提示、无需额外操作。
6. 测试和浏览器均只连接本地数据库，不向 Cloudflare 生产写入测试样本。
